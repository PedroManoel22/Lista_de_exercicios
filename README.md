# 🐍 Resolução da Lista de Exercícios de Python (Dunossauro)

Este repositório contém as minhas resoluções práticas para a renomada [Lista de Exercícios de Python](https://exercicios.dunossauro.com/) do curso **Python Pro** (comunidade Dunossauro). O objetivo principal deste projeto é consolidar fundamentos sólidos em desenvolvimento Python, aplicando conceitos de Orientação a Objetos (POO), manipulação de arquivos, expressões regulares (RegEx) e arquiteturas limpas.

O repositório foi construído seguindo rigorosos padrões profissionais de mercado, visando boas práticas de código, legibilidade e manutenibilidade.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Python 3.14+**: Utilizando recursos modernos da linguagem.
- **Pylance / Mypy**: Análise estática com tipagem estrita (*Strict Type Checking*).
- **Ruff / Black**: Ferramentas de formatação de código e aplicação de regras da PEP 8.
- **Git / GitHub**: Versionamento estruturado utilizando boas práticas de commits.
